# Sumi CSS - 듀얼 렌더링 엔진 및 조형 무결성 거버넌스 (04_DUAL_ENGINE)

> **"아날로그 서예의 깊은 '손맛'과 차세대 모던 웹의 '벡터 효율성'의 조화"**  
> 본 문서는 Sumi CSS의 듀얼 렌더링 엔진(비트맵 vs SVG) 구조, 5대 비교 평가지표, 그리고 에셋과 스타일의 품격을 지키기 위한 조형 무결성 거버넌스 명세서입니다.

---

## 1. 듀얼 렌더링 엔진 아키텍처 (Dual Rendering Engine)

Sumi CSS는 서예 특유의 아날로그 '손맛'과 차세대 웹의 초경량 벡터 효율성을 객관적으로 비교·선택할 수 있도록 **듀얼 렌더링 엔진** 구조를 채택했습니다.

### 1) 비트맵 엔진 (`data-sumi-engine="bitmap"`)
* **특징**: 실제 서예가의 필선, 미세 붓털 갈필(渴筆), 먹물 흡수 번짐의 유기적인 질감을 100% 온전하게 표현합니다.
* **로딩 전략**: 최신 브라우저는 고압축 WebP 우선 로딩, 구형 브라우저는 원본 PNG/JPG 자동 폴백.
* **렌더링 부하**: 브라우저 이미지 디코딩 후 GPU 단순 텍스처 페인팅으로 저사양 기기에서도 안정적인 60fps를 보장합니다.

### 2) 차세대 SVG 벡터 엔진 (`data-sumi-engine="svg"`)
* **특징**: 인라인 SVG 심볼(`<symbol id="sumi-svg-brush">`, `#sumi-svg-enso`) 및 SVG 패스 마스크를 활용합니다.
* **네트워크 오버헤드 0KB**: HTML 내 인라인 번들링으로 외부 네트워크 요청 없이 즉시 렌더링됩니다.
* **무한 해상도 선명도**: 4K/8K 모니터, 모바일 레티나, 400% 고배율 확대에서도 래스터 블러 없이 칼같은 선명도를 유지합니다.
* **CSS 동적 테마 연동**: CSS `currentColor`, `fill`, `stroke` 변수 하나로 임의의 색상 안료에 실시간 대응합니다.

---

## 2. SVG 배경 폐기 결정 원칙 (Architecture Decision)

> [!IMPORTANT]
> **SVG 배경 폐기 원칙 (천연 닥나무 섬유결 비트맵 일원화)**  
> 인라인 SVG `<feTurbulence>` 필터를 이용한 배경 텍스처 합성은 렌더링 시 **인위적인 가로 줄무늬 노이즈**와 **심각한 본문 가독성 저하**를 초래하여 **전면 폐기**되었습니다.  
> 따라서 렌더 엔진 설정(`bitmap` / `svg`)과 무관하게, 화선지 바탕은 항상 **72.7KB 고압축 WebP 천연 화선지 비트맵(`hanji-bg.webp`)으로 일원화**되어 고서의 품격과 가독성을 보장합니다.

## 3. 5대 평가 지표 (Evaluation Matrix) & 승자 판정

두 엔진은 쇼케이스 내 1:1 Side-by-Side 및 400% 줌 렌즈를 통해 실시간 검증되며, 5대 평가 지표에 따른 비교 결과는 다음과 같습니다:

| 평가 지표 | 비트맵 방식 (WebP / PNG) | SVG 벡터 방식 (SVG Engine) | 승자 판정 |
| :--- | :--- | :--- | :---: |
| **전송량 (Transfer Size)** | WebP 압축 시 약 60~100KB (원본 431KB) | 인라인 코드 약 1~3KB (다운로드 0KB) | **SVG 압승** (다운로드 오버헤드 제로) |
| **시각적 손맛 (Artistic Fidelity)** | 서예가의 실제 붓질, 비백, 화선지 번짐 손맛 100% 보존 | 수학적 베지어 곡선으로 인해 미세하게 인위적일 가능성 | **비트맵 우세** (서예 미학 1:1 합치) |
| **디스플레이 확장성 (High DPI)** | 고배율 모바일 화면이나 400% 확대 시 미세 래스터 블러 발생 | 어떤 고해상도(4K/8K/레티나)에서도 칼같은 선명도 유지 | **SVG 압승** (무한 해상도) |
| **렌더링 부하 (Scroll FPS)** | 브라우저 디코딩 후 GPU 단순 페인팅 (부하 극소) | 복잡한 SVG 패스 연산 시 저사양 기기 최적화 필요 | **비트맵 우세** (안정적 60fps 보장) |
| **테마 확장성 (Color Tuning)** | 색상별 별도 이미지 파일(PNG 12종 등) 사전 준비 필요 | CSS fill/stroke 변수 하나로 임의의 색상 즉시 대응 | **SVG 압승** (동적 테마 연동) |

## 4. 조형 무결성 거버넌스 (Design Integrity Governance)

Sumi CSS의 본질은 **서예 특유의 긴장감 있는 날렵한 선율(6~8px)과 맑은 여백**에 있습니다. 에셋이나 스타일을 유지보수·개선할 때 다음 5대 원칙을 절대 훼손하지 않아야 합니다:

1. **과도한 두께 확장 금지 (Anti-Bulking)**:
   - 프로그레스 바와 슬라이더의 컨테이너 높이는 `12px`(중앙 획 두께 6~8px)를 절대 기준으로 유지합니다.
   - 임의로 서예 대자 글씨를 키워 20px 이상의 몽둥이 같은 둔탁한 획으로 교체하지 않습니다.
   - 모바일 터치 접근성 확보 시에는 획 두께를 키우지 않고, 보이지 않는 터치 인터랙션 영역(`44px`)만 확장합니다.
2. **기필(起筆)과 수필(收筆)의 보존**:
   - 시작점은 둥글고 도톰한 유선형 기필 머리를 유지하고, 사각형으로 칼같이 잘린 획을 쓰지 않습니다.
   - 끝단은 오른쪽으로 갈수록 자연스럽게 가늘어지는 테이퍼링(Tapering) 소멸 궤적을 보존합니다.
3. **트랙과 채움의 1:1 실루엣 합치**:
   - `sumi-stroke-track.png`(담묵)와 `sumi-stroke-fill.png`(농묵)는 완전히 동일한 윤곽 마스크를 공유해야 하며, 서로 다른 형태의 에셋을 조합하지 않습니다.
4. **신축 대응 디바이더의 슬림함 유지**:
   - 가로형 디바이더(`brush-divider-1~3.png`)와 세로형 디바이더(`brush-divider-vertical.png`)는 레이아웃 폭이 늘어나더라도 두께 6~10px의 맑고 우아한 선을 유지해야 합니다.
5. **자연스러운 화선지 질감 보존**:
   - 인위적인 기계적 노이즈 필터로 화선지 배경을 대체하지 않으며, 고압축 천연 화선지 비트맵 에셋을 표준으로 유지합니다.
