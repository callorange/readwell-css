Readwell CSS 공식 가이드

E-Ink 디스플레이에서 영감을 얻은 긴 글 가독성과 제품 UI를 위한 저자극 순수 CSS 프레임워크입니다. 모든 컴포넌트는 Zero Runtime JavaScript 및 표준 시맨틱 HTML5 태그를 기반으로 작동합니다.

1. Getting Started (시작하기)

개요 및 디자인 철학

Readwell CSS는 장시간 화면을 보아도 눈이 피로하지 않은 차분한 가독성과 실제 상용 제품 UI(Workspace, Dashboard, Backoffice)에 필요한 구조적 명확성을 함께 제공합니다.

  • 절제된 페이퍼 미학: 화려한 그림자, 과한 테두리 반경, 불필요한 모션을 억제하고 단정한 선과 여백으로 위계를 표현합니다.
  • 저채도 Semantic Matrix: 6종 상태 색상(primary, secondary, success, warning, danger, info)을 저채도로 조화롭게 적용합니다.
  • Zero Runtime Dependencies: 별도의 자바스크립트 없이 HTML5 표준 요소만으로 컴포넌트가 완성됩니다.

빠른 시작 (Installation)

단일 CDN 링크 또는 로컬 빌드 파일을 HTML 문서 상단에 삽입하면 즉시 적용됩니다.

<!-- CDN 링크로 빠르게 불러오기 -->
<link rel="stylesheet" href="https://callorange.github.io/readwell-css/dist/readwell.min.css">

<!-- 기본 HTML 마크업 예시 -->
<main class="rw-container" data-rw-theme="warm" data-rw-surface="reading" data-rw-density="cozy">
  <article class="rw-reading">
    <h1>읽는 시간이 길수록 조용한 화면이 좋아진다.</h1>
    <p>본문 내용을 편안하게 작성하세요...</p>
  </article>
</main>

🎛️ 4대 HTML 제어 속성 (data-rw-*)

HTML <body> 또는 <html> 태그에 속성을 부여하여 전역 모드를 선언적으로 제어합니다.

제어 속성 옵션 값 기본값 설명 및 권장 용도
data-rw-theme light, warm light 테마 색온도: 내추럴 백상지(Light) vs 단행본 미색 크림지(Warm)
data-rw-surface reading, workspace, dashboard, dense reading 화면 표면: 장문 독서 / 문서 협업 / 운영 콘솔 / 고밀도 데이터 표
data-rw-density cozy, comfortable, compact comfortable 여백 밀도: 여유로운 여백 / 표준 균형 / 압축 데이터 뷰
data-rw-eink true, false false 전자종이 정적 모드: 모든 전환 효과 및 애니메이션 차단

퓨어 페이퍼 테마 듀오 (Pure Paper Duo)

E-Ink 및 인쇄 종이 매체의 자연스러운 질감을 살린 2종의 표준 테마입니다.

Light 📄 (내추럴 백상지)

맑고 정갈한 순수 종이 질감으로 깔끔하고 현대적인 가독성을 제공합니다.

Warm Paper 📖 (단행본 크림지)

단행본 출판 도서의 미색 크림지 질감으로 장시간 독서 시 눈의 피로를 최소화합니다.

2. Layout (레이아웃)

Container & Reading

.rw-container는 페이지 최대 폭(72rem)을 안정적으로 제한하며, .rw-reading은 긴 글 가독성을 위해 본문 폭을 44rem으로 최적화합니다.

.rw-container (기본 컨테이너 영역)
.rw-reading (최대 44rem 독서 최적화 영역) 
<div class="rw-container">
  <article class="rw-reading">
    <h1>장문 아티클 제목</h1>
    <p>한 줄의 길이가 너무 길지 않아 눈이 피로하지 않습니다.</p>
  </article>
</div>

Grid (그리드)

.rw-grid-2, .rw-grid-3을 통해 반응형 멀티 컬럼 레이아웃을 손쉽게 구성합니다.

Column 1
Column 2
Column 3
<div class="rw-grid-2">
  <div class="rw-panel">2열 그리드 좌측</div>
  <div class="rw-panel">2열 그리드 우측</div>
</div>

<div class="rw-grid-3">
  <div class="rw-panel">3열 그리드 A</div>
  <div class="rw-panel">3열 그리드 B</div>
  <div class="rw-panel">3열 그리드 C</div>
</div>

Stack & Cluster

.rw-stack은 수직 흐름 여백을 부여하고, .rw-cluster는 버튼이나 태그의 수평 나열에 활용됩니다.

Cluster Badge 
<div class="rw-cluster">
  <button class="rw-button--primary">확인</button>
  <button class="rw-button--secondary">취소</button>
</div>

Sidebar Layout & App Shell

.rw-sidebar-layout은 본문과 사이드바(280px)를 자연스럽게 분할하는 문서형 제품 구조를 제공합니다.

3. Typography & Content (콘텐츠)

Typography (제목 & 본문)

별도의 클래스 없이 기본 HTML 태그(h1~h6, p)만으로 단정한 위계와 행간(1.7)이 적용됩니다.

Heading 1 (2.2rem)

Heading 2 (1.6rem)

Heading 3 (1.25rem)

본문 단락(Paragraph)입니다. 전자종이 디스플레이의 시각적 안정성을 브라우저 환경에 이식하여 눈의 피로를 최소화합니다.

<h1>대제목</h1>
<h2>중제목</h2>
<p>본문 단락입니다.</p>

Blockquote & Code Block

인용문과 코드 블록은 과한 배경색 없이 단정한 보더와 여백으로 내용을 부각합니다.

"읽는 시간이 길수록 조용한 화면이 좋아진다." — Readwell Team
const readwell = { mode: 'pure-paper', runtime: 'zero-js' };
<blockquote>"인용문 내용"</blockquote>
<pre><code>const code = "Hello Readwell";</code></pre>

Tables (데이터 표)

선과 여백 중심의 미니멀 데이터 테이블로, 밀도(Density) 설정에 따라 셀 여백이 유기적으로 조절됩니다.

이름 역할 상태
김개발 엔지니어 정상 운영
이디자인 디자이너 작업 중 
<div class="rw-table-container">
  <table>
    <thead>
      <tr><th>항목</th><th>상태</th></tr>
    </thead>
    <tbody>
      <tr><td>서버</td><td><span class="rw-badge rw-badge--success">정상</span></td></tr>
    </tbody>
  </table>
</div>

Badges & Meta (상태 라벨 & 메타)

6종 저채도 시맨틱 배지와 보조 메타 텍스트(.rw-meta)입니다.

Default Primary Secondary Success Warning Danger Info 
<span class="rw-badge rw-badge--primary">Primary</span>
<span class="rw-badge rw-badge--success">Success</span>
<span class="rw-meta">2026.09.02 · 읽기 5분</span>

4. Forms & Validation (폼 입력 및 검증)

Input, Select & Textarea

밀도 시스템과 연동되는 기본 폼 컨트롤입니다.

<label class="rw-meta">이름</label>
<input type="text" placeholder="홍길동">

<label class="rw-meta">구분</label>
<select>
  <option>옵션 1</option>
</select>

Custom Checkbox & Radio

Paper & Ink 철학에 부합하는 순수 CSS 사각/원형 커스텀 컨트롤입니다.

<label><input type="checkbox" checked> 동의함</label>
<label><input type="radio" name="group" checked> 선택 1</label>

Toggle Switch

role="switch" 속성만으로 슬라이더 스위치로 전환됩니다.

<label>
  <input type="checkbox" role="switch" checked> 모드 활성화
</label>

Valid & Invalid 유효성 검증 상태

웹 접근성 표준 aria-invalid 속성에 기반하여 성공 및 오류 상태를 명확히 표현합니다.

✓ 사용 가능한 도메인입니다.
유효한 이메일 형식이 아닙니다. 
<!-- 성공 상태 (Valid) -->
<input type="text" value="readwell.design" aria-invalid="false">
<span class="rw-form-success">✓ 사용 가능한 도메인입니다.</span>

<!-- 오류 상태 (Invalid) -->
<input type="email" value="wrong-email" aria-invalid="true">
<span class="rw-form-error">유효한 이메일 형식이 아닙니다.</span>

5. Components (컴포넌트)

Button & Button Group

단일 버튼 및 결합형 버튼 그룹(.rw-button-group)입니다.

<button class="rw-button--primary">확인</button>

<div class="rw-button-group">
  <button class="is-active" aria-pressed="true">옵션 1</button>
  <button aria-pressed="false">옵션 2</button>
</div>

Card (.rw-card) vs Panel (.rw-panel)

.rw-card는 독립된 콘텐츠 단위(기사, 상품)를, .rw-panel은 화면의 구조적 구획(사이드바, 설정 박스)을 담당합니다.

.rw-card (콘텐츠 카드)

독립된 읽기 단위를 표현합니다.

.rw-panel (구조 패널)

배경 및 구조적 영역을 분할합니다.

<article class="rw-card">카드 콘텐츠</article>
<div class="rw-panel">패널 구획</div>

Callouts / Alerts (4종 알림 메시지)

안내, 성공, 경고, 오류 알림 박스입니다.

Info: 새로운 버전 v0.1.0이 배포되었습니다.
Success: 작업이 정상적으로 완료되었습니다.
Warning: 저장되지 않은 변경사항이 있습니다.
Danger: 연결이 끊어졌습니다. 다시 시도하세요.
<div class="rw-callout rw-callout--info">안내 메시지</div>
<div class="rw-callout rw-callout--success">성공 메시지</div>
<div class="rw-callout rw-callout--warning">주의 메시지</div>
<div class="rw-callout rw-callout--danger">오류 메시지</div>

Accordion / Disclosure (details.rw-accordion)

HTML5 표준 <details> 태그만으로 동작하는 아코디언입니다.

자주 묻는 질문 1: Readwell CSS는 자바스크립트가 필요한가요?
아닙니다. 100% 순수 CSS와 HTML5 표준 태그만으로 모든 컴포넌트가 동작합니다. 
<details class="rw-accordion">
  <summary>아코디언 제목</summary>
  <p>펼쳐지는 상세 본문 내용...</p>
</details>

Modal Dialog (<dialog>)

HTML5 네이티브 <dialog> 태그에 최적화된 모달 스타일입니다.

네이티브 모달 다이얼로그

브라우저 표준 <dialog> 요소를 사용하여 백드롭과 접근성이 기본 보장됩니다.

 
<dialog id="my-dialog" class="rw-dialog">
  <form method="dialog" class="rw-stack">
    <h3>모달 제목</h3>
    <p>모달 내용...</p>
    <button type="submit">닫기</button>
  </form>
</dialog>

Dropdown (Zero-JS 네이티브 드롭다운)

details.rw-dropdown 구조로 자바스크립트 없이 4px 밀착 메뉴가 열립니다.

옵션 선택 ▾
  • 프로필 설정
  • 팀 워크스페이스
  • 로그아웃
<details class="rw-dropdown">
  <summary class="rw-button">옵션 메뉴 ▾</summary>
  <ul class="rw-dropdown-menu">
    <li><a href="#" class="rw-dropdown-item">설정</a></li>
    <li class="rw-dropdown-divider"></li>
    <li><a href="#" class="rw-dropdown-item">로그아웃</a></li>
  </ul>
</details>

Progress Bar (<progress>)

HTML5 표준 진행률 표시줄입니다.

<progress value="65" max="100" style="width: 100%;"></progress>

6. Product Patterns (제품형 UI 패턴)

Stat Card (지표/통계 카드)

대시보드와 모니터링 콘솔에 사용되는 메트릭 카드입니다.

128,450
↑ 14.2% 전월 대비
평균 완독률
84.6%
↑ 3.1% 전월 대비
<div class="rw-stat rw-panel">
  <span class="rw-meta">지표 명칭</span>
  <div class="rw-stat__value">128,450</div>
  <div class="rw-stat__diff">↑ 14.2% 증가</div>

Empty State (.rw-empty)

데이터가 없을 때 보여주는 단정한 엠프티 스테이트입니다.

등록된 문서가 없습니다

새로운 글을 작성하여 지식 베이스를 구축해 보세요.

<div class="rw-empty">
  <p>데이터가 없습니다</p>
  <button class="rw-button--primary">생성하기</button>
</div>

7. Modes & Customization (모드 및 커스터마이징)

Surface Family (화면 표면)

data-rw-surface 속성으로 용도별 화면 특성을 지정합니다.

  • reading: 장문 독서 최적화 (본문 폭 48rem 제한 및 넉넉한 타이포 행간)
  • workspace: 문서형 협업 도구 및 사이드바 레이아웃 (컨테이너 80rem)
  • dashboard: 운영 콘솔 및 지표 그리드 (컨테이너 84rem)
  • dense: 고밀도 데이터 테이블 및 필터 (컴팩트 밀도 자동 활성화)

Density System (여백 밀도)

data-rw-density 속성으로 테이블 셀, 버튼, 인풋, 그리드 여백을 유기적으로 조절합니다.

  • cozy: 터치 인터페이스 및 여유로운 독서 여백
  • comfortable: 표준 균형 여백 (기본값)
  • compact: 대량 데이터 조회를 위한 압축 뷰

E-Ink Mode (전자종이 정적 렌더링 모드)

data-rw-eink="true" 속성 또는 @media (update: slow) 환경에서 모든 애니메이션과 전환 효과를 차단하여 눈 피로를 완벽히 제거합니다.
