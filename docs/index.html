Readwell CSS 공식 가이드

E-Ink 디스플레이에서 영감을 얻은 긴 글 가독성과 제품 UI를 위한 저자극 순수 CSS 프레임워크입니다. 모든 컴포넌트는 Zero Runtime JavaScript 및 표준 시맨틱 HTML5 태그를 기반으로 작동합니다.

1. Getting Started (시작하기)

개요 및 디자인 철학

Readwell CSS는 장시간 화면을 보아도 눈이 피로하지 않은 차분한 가독성과 실제 상용 제품 UI(Workspace, Dashboard, Backoffice)에 필요한 구조적 명확성을 함께 제공합니다.

  • 절제된 페이퍼 미학: 화려한 그림자, 과한 테두리 반경, 불필요한 모션을 억제하고 단정한 선과 여백으로 위계를 표현합니다.
  • 저채도 Semantic Matrix: 6종 상태 색상(primary, secondary, success, warning, danger, info)을 저채도로 조화롭게 적용합니다.
  • Zero Runtime Dependencies: 별도의 자바스크립트 없이 HTML5 표준 요소만으로 컴포넌트가 완성됩니다.

빠른 시작 (Installation)

단일 CDN 링크 또는 로컬 빌드 파일을 HTML 문서 상단에 삽입하면 즉시 적용됩니다.

<!-- CDN 링크로 빠르게 불러오기 -->
<link rel="stylesheet" href="https://callorange.github.io/readwell-css/dist/readwell.min.css">

<!-- 기본 HTML 마크업 예시 -->
<main class="rw-container" data-rw-theme="warm" data-rw-layout="reading">
  <article class="rw-reading">
    <h1>읽는 시간이 길수록 조용한 화면이 좋아진다.</h1>
    <p>본문 내용을 편안하게 작성하세요...</p>
  </article>
</main>

🎛️ 4대 HTML 제어 속성 (data-rw-*)

HTML <body> 또는 <html> 태그에 속성을 부여하여 전역 모드를 선언적으로 제어합니다. 스마트 프리셋 체계로 data-rw-layout만 지정해도 최적의 밀도가 자동 연동됩니다.

제어 속성 옵션 값 기본값 설명 및 권장 용도
data-rw-theme light, warm, dark light 테마 색온도: 내추럴 백상지(Light) vs 단행본 미색 크림지(Warm) vs 먹빛 흑연 야간지(Dark)
data-rw-layout
(구 surface 호환)		 reading, docs, workspace, fluid reading 레이아웃 아키타입 & 스마트 프리셋: 화면 목적별 최적 폭 및 기본 밀도 자동 연동 (reading[48rem]➔cozy, docs[80rem]➔comfortable, workspace[90rem]➔comfortable, fluid[100%]➔compact)
data-rw-density cozy, comfortable, compact 스마트 프리셋 연동 밀도 미세 조절 (오버라이드): 스마트 프리셋 기본값을 덮어쓰고 개별 패딩·여백을 수동 미세 조정할 때 사용
data-rw-eink true, false false 전자종이 정적 모드: 모든 전환 효과 및 애니메이션 차단

퓨어 페이퍼 테마 트리오 (Pure Paper Trio)

E-Ink 및 인쇄 종이 매체의 자연스러운 질감을 살린 3종의 표준 종이 테마입니다.

Light 📄 (내추럴 백상지) 기본 테마

맑고 정갈한 순수 종이 질감으로 깔끔하고 현대적인 가독성을 제공합니다.

조용한 화면이 만드는 집중

긴 글 읽기와 업무용 워크스페이스에 최적화된 시각 대비를 선사합니다.

Warm Paper 📖 (단행본 크림지) 눈 피로 완화

단행본 출판 도서의 미색 크림지 질감으로 장시간 독서 시 블루라이트 자극을 줄입니다.

단행본 질감의 편안함

실제 출판 책의 미색 용지 색온도를 재현하여 편안한 시야를 유지합니다.

Dark 🌙 (먹빛 흑연 야간지) 야간 저자극

칠흑 블랙 대신 눈부심 없는 흑연 먹빛으로 장시간 야간 독서 및 코딩에 적합합니다.

먹지 질감의 차분함

어두운 방에서도 대비 자극 없이 정보를 또렷하게 판독할 수 있습니다.

2. Layout (레이아웃)

Container & Reading

.rw-container는 페이지 최대 폭(80rem)을 안정적으로 제한하며, .rw-reading은 긴 글 가독성을 위해 본문 폭을 48rem으로 최적화합니다.

.rw-container (기본 컨테이너 영역)
.rw-reading (최대 48rem 독서 최적화 영역) 
<div class="rw-container">
  <article class="rw-reading">
    <h1>장문 아티클 제목</h1>
    <p>한 줄의 길이가 너무 길지 않아 눈이 피로하지 않습니다.</p>
  </article>
</div>

Sidebar Layout & App Shell

.rw-sidebar-layout--left는 좌측 사이드바(250px 고정)와 우측 본문(1fr) 구조를, .rw-sidebar-layout은 좌측 본문(1fr)과 우측 목차(260px) 구조를 지원합니다. 

<!-- 좌측 사이드바 + 우측 본문 문서 레이아웃 -->
<div class="rw-container rw-sidebar-layout--left">
  <aside>사이드바 메뉴 (250px)</aside>
  <main>본문 콘텐츠 영역 (1fr)</main>

Text Weights & Styles (텍스트 굵기 및 강조 서식)

진하게, 연하게, 이탤릭, 굵기 단계별 시맨틱 태그 및 유틸리티 클래스입니다.

진하게 (strong 태그 / .rw-bold): 핵심 키워드나 중요한 문장을 굵게(700) 표현합니다.

세미볼드 (.rw-semibold): 적절한 무게감(600)으로 UI 레이블을 강조합니다.

일반 굵기 (.rw-normal): 표준 본문 굵기(400)입니다.

가벼운 굵기 (.rw-light): 은은하고 얇은 굵기(300)입니다.

기울임꼴 (em / i 태그 / .rw-italic): 인용이나 강조 문장에 기울임 스타일을 적용합니다.

연하게 (small 태그 / .rw-muted): 부가 설명이나 보조 텍스트를 차분한 저채도 회색으로 표현합니다. 

<strong>진하게 (700)</strong> 또는 <span class="rw-bold">...</span>
<span class="rw-semibold">세미볼드 (600)</span>
<span class="rw-normal">일반 굵기 (400)</span>
<span class="rw-light">가벼운 굵기 (300)</span>
<em>기울임꼴</em>
<small class="rw-muted">연하게 보조 텍스트</small>

Inline Text (인라인 서식: kbd, mark, del, ins, samp 등)

표준 HTML5 인라인 텍스트 요소를 품격 있는 페이퍼 질감으로 스타일링합니다.

단축키를 누르려면 Ctrl + Shift + R 키를 입력하세요.

중요한 핵심 문장은 형광펜 하이라이트(mark)로 강조됩니다.

수정 전 내용은 취소선(del) 처리되고, 새로 추가된 내용은 추가선(ins)으로 표현됩니다.

터미널 출력 표본은 npm run build --success 형태로 나타납니다.

수학/화학식의 첨자: H2O (아래첨자) 및 E = mc2 (위첨자)

용어 설명 툴팁: CSS 및 HTML5 

<kbd>Ctrl</kbd> + <kbd>C</kbd>
<mark>형광펜 하이라이트</mark>
<del>취소선</del> / <ins>추가선</ins>
<samp>출력 결과</samp>
H<sub>2</sub>O / E = mc<sup>2</sup>
<abbr title="설명">약어</abbr>

Tufte-Style Sidenotes & Footnotes (사이드노트 및 본문 각주)

에드워드 터프티(Edward Tufte) 스타일의 장문 독서 최적화 각주 시스템입니다. 데스크톱(1080px 이상)에서는 본문 우측 마진에 나란히 배치되고, 모바일에서는 접이식 인라인 카드로 자동 반응형 전환됩니다.

긴 기술 문서나 아티클을 읽을 때 본문의 시선 흐름을 깨뜨리지 않고 참고 자료를 전달하는 것은 대단히 중요합니다. 사이드노트는 데스크톱에서 본문과 동일한 행 높이의 우측 여백에 배치되어 시선 분산을 방지합니다. 번호가 필요 없는 보조 메모의 경우 기호형 마진노트를 사용할 수도 있습니다. 마진노트는 번호 없이 자연스러운 주석 메모를 남길 때 유용합니다.

  1. 마크다운 및 출판 표준 규격의 하단 각주 예시입니다. ↩
<!-- 1. 표준 사이드노트 (번호 자동 매김) -->
본문 텍스트입니다.<label for="sn-1" class="rw-sidenote-number"></label>
<input type="checkbox" id="sn-1" class="rw-sidenote-toggle rw-sr-only">
<span class="rw-sidenote">데스크톱에서는 우측 마진에 부유하고 모바일에서는 접이식으로 변환됩니다.</span>

<!-- 2. 기호형 마진노트 (번호 없음) -->
참고 문장입니다.<label for="mn-1" class="rw-marginnote-symbol">⊕</label>
<input type="checkbox" id="mn-1" class="rw-marginnote-toggle rw-sr-only">
<span class="rw-marginnote">단순 보조 메모용 마진노트입니다.</span>

<!-- 3. 학술/출판 하단 각주 목록 -->
<section class="rw-footnotes" aria-label="Footnotes">
  <ol>
    <li id="fn-1">각주 설명 문구 <a href="#fnref-1" class="rw-footnote-backref">↩</a></li>
  </ol>
</section>

Blockquote & Code Block

인용문과 코드 블록은 과한 배경색 없이 단정한 보더와 여백으로 내용을 부각합니다.

"읽는 시간이 길수록 조용한 화면이 좋아진다." — Readwell Team
const readwell = { mode: 'pure-paper', runtime: 'zero-js' };
<blockquote>"인용문 내용"</blockquote>
<pre><code>const code = "Hello Readwell";</code></pre>

HTML 태그에 data-rw-theme="warm" 및 data-rw-mode="night" 속성을 지정하면 즉시 전환됩니다.

</details>

7. Modes & Customization (모드 및 커스터마이징)

Layout Archetypes & Smart Presets (레이아웃 및 스마트 프리셋)

data-rw-layout 속성으로 용도별 화면 특성을 지정하면 최적의 밀도가 자동 연동됩니다. (기존 data-rw-surface와도 100% 호환됩니다.)

  • reading: 1컬럼 장문 독서 최적화 (본문 폭 48rem, 넉넉한 1.75 행간 + 기본 Cozy 밀도 자동 연동)
  • docs: 2컬럼 공식 기술 문서 (컨테이너 80rem, 목차 TOC + 본문 가이드 + 기본 Comfortable 밀도 자동 연동)
  • workspace: 3패널 협업 도구 및 대시보드 뷰 (컨테이너 90rem, 사이드바 + 본문 + 속성 패널 + 기본 Comfortable 밀도 자동 연동)
  • fluid (records/dense): 전폭 백오피스 및 고밀도 데이터 테이블 (폭 100% + 기본 Compact 밀도 자동 연동)

Density Fine-tuning (여백 밀도 미세 조절 & 오버라이드)

스마트 프리셋 기본값을 변경하고 싶을 때 data-rw-density 속성으로 버튼, 인풋, 테이블, 그리드 여백을 수동 오버라이드합니다.

  • cozy: 터치 인터페이스 및 여유로운 독서 여백
  • comfortable: 표준 균형 데스크톱 여백
  • compact: 대량 데이터 조회를 위한 압축 초소형 뷰

E-Ink Mode (전자종이 정적 렌더링 모드)

data-rw-eink="true" 속성 또는 @media (update: slow) 환경에서 모든 애니메이션과 전환 효과를 차단하여 눈 피로를 완벽히 제거합니다.

Print Optimization (@media print)

브라우저 인쇄(Ctrl+P) 또는 PDF 내보내기 시 별도의 조작 없이 출판물 규격으로 자동 최적화됩니다.

  • UI 자동 숨김: 내비게이션 바, 툴바, 버튼, 컨트롤 패널 등 인터랙티브 UI 자동 제외
  • 순백색 & 순먹색 전환: 잉크 절약 및 100% 흑백 대비 보장
  • 페이지 나눔 방지: 표, 카드, 인용구, 코드 블록 중간에서 페이지가 잘리는 현상 방지
  • 링크 각주 표기: 본문 내 외부 링크 URL 자동 각주화 (a[href]::after)
