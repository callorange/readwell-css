Readwell CSS는 E-Ink의 외형을 복제하지 않고, 오래 읽기 편한 제약을 일반 웹 UI 규칙으로 옮기는 CSS 프레임워크입니다.

컴포넌트 전략

Card, accordion, switch, breadcrumb, pagination처럼 실제 서비스에 필요한 기본 컴포넌트는 제공하되, 복잡한 JavaScript behavior는 core에서 담당하지 않습니다.

Accordion

Readwell은 collapse animation을 제공하나요?

기본적으로 제공하지 않습니다. details/summary의 native 동작을 사용하고, 상태 변화는 즉시 일어나도 괜찮다는 쪽을 기본값으로 둡니다.

Dialog나 tabs는 어떻게 처리하나요?

Readwell은 visual style만 제공합니다. 여닫기, selected state 변경, keyboard interaction은 사용자 코드나 별도 라이브러리가 담당합니다.
