# Readwell CSS Dark Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Readwell CSS에 저자극 E-Ink 인버스 다크 모드(`[data-rw-theme="dark"]` 및 `@media (prefers-color-scheme: dark)`) 토큰 및 스타일을 구현하고, 모드 스위처 및 전체 예제에 연동

**Architecture:** `src/modes.css`에 `@layer modes` 또는 `src/tokens.css`에 다크 모드 토큰 오버라이드 룰셋을 정의하고, 빌드 스크립트(`scripts/build.js`)로 컴파일. `examples/switcher.js`에 테마 선택기(Auto/Light/Dark)를 추가하여 실시간 테마 전환 및 `localStorage` 지속성 제공.

**Tech Stack:** Pure CSS3 (`@layer`, CSS Custom Properties), Vanilla JavaScript

**Spec:** [docs/superpowers/specs/2026-09-02-dark-mode-design.md](file:///d:/Projects/Private/readwell-css/docs/superpowers/specs/2026-09-02-dark-mode-design.md)

## Global Constraints

- 코어 CSS 라이브러리의 무결성 유지 및 `@layer` 순서 준수
- E-Ink 다크 모드는 순수 블랙(#000000)이 아닌 차분한 다크 차콜(#191c18) 기반
- 모든 Semantic Color는 WCAG AA/AAA 명도 대비(Contrast Ratio) 충족
- 모든 파일 I/O는 UTF-8 인코딩 및 POSIX LF 줄바꿈 적용
