2. Layout (레이아웃)

Container & Reading

.rw-container는 페이지 최대 폭(80rem)을 안정적으로 제한하며, .rw-reading은 긴 글 가독성을 위해 본문 폭을 48rem으로 최적화합니다.

.rw-container (기본 컨테이너 영역)
.rw-reading (최대 48rem 독서 최적화 영역) 
<div class="rw-container">
  <article class="rw-reading">
    <h1>장문 아티클 제목</h1>
    <p>한 줄의 길이가 너무 길지 않아 눈이 피로하지 않습니다.</p>
  </article>
</div>

.rw-grid-3 (3열 그리드)

Col 2 of 3
Col 3 of 3
.rw-grid-4 (4열 그리드)

Col 4/4

.rw-col-span-12 (전체 12칸 / 100%)
.rw-col-span-8 (8칸 / 66.6%)
.rw-col-span-4 (4칸 / 33.3%)

Stack (.rw-stack) & Cluster (.rw-cluster)

.rw-stack은 수직 흐름에 일정한 간격(밀도 토큰 --rw-density-gap)을 부여하며, .rw-cluster는 버튼이나 태그의 수평 나열(줄바꿈 지원)에 활용됩니다.

.rw-stack (수직 스택 흐름)
스택 아이템 1 (상단)
스택 아이템 2 (중간)
스택 아이템 3 (하단)
.rw-cluster (수평 클러스터 나열)
Badge 
<!-- 수직 흐름 스택 -->
<div class="rw-stack">
  <div class="rw-panel">상단 영역</div>
  <div class="rw-panel">하단 영역</div>
</div>

<!-- 수평 클러스터 -->
<div class="rw-cluster">
  <button class="rw-button">버튼 1</button>
  <button class="rw-button">버튼 2</button>
</div>

Sidebar Layout & App Shell

.rw-sidebar-layout--left는 좌측 사이드바(250px 고정)와 우측 본문(1fr) 구조를, .rw-sidebar-layout은 좌측 본문(1fr)과 우측 목차(260px) 구조를 지원합니다. 

<!-- 좌측 사이드바 + 우측 본문 문서 레이아웃 -->
<div class="rw-container rw-sidebar-layout--left">
  <aside>사이드바 메뉴 (250px)</aside>
  <main>본문 콘텐츠 영역 (1fr)</main>
</div>
