4. Forms & Validation (폼 컨트롤 및 유효성 검증)

Input, Select & Textarea

밀도 시스템과 연동되는 기본 폼 컨트롤입니다.

<label class="rw-meta">이름</label>
<input type="text" placeholder="홍길동">

<label class="rw-meta">소개</label>
<textarea rows="3" placeholder="내용 입력..."></textarea>

Custom Checkbox & Radio

Paper & Ink 철학에 부합하는 순수 CSS 사각/원형 커스텀 컨트롤입니다. 완벽한 네이티브 포커스 링과 라벨 클릭 토글을 지원합니다. 

<label>
  <input type="checkbox" checked> 동의함
</label>

<label>
  <input type="radio" name="group" checked> 옵션 A
</label>
<label>
  <input type="radio" name="group"> 옵션 B
</label>

Toggle Switch (슬라이더 스위치)

표준 체크박스에 role="switch" 속성만 부여하면 슬라이더 토글 스위치로 자동 전환됩니다. 

<label>
  <input type="checkbox" role="switch" checked> 자동 저장 활성화
</label>

Slider Range Control (<input type="range">)

E-Ink 독서 화면의 글자 크기, 줄 간격, 화면 밀도 등을 부드럽게 조절할 수 있는 미니멀 Paper & Ink 슬라이더입니다. 호버 시 썸(Thumb) 확대 피드백과 네이티브 포커스 링을 지원합니다.

기본값: 16px 
<!-- 표준 슬라이더 컨트롤 -->
<label class="rw-meta">글자 크기</label>
<input type="range" min="12" max="24" value="16">

<!-- 비활성화 상태 -->
<input type="range" disabled>

Input Group (결합 입력창 .rw-input-group)

텍스트 입력 필드 좌우에 고정 단위(₩, $, %), 프로토콜(https://), 검색 버튼 등을 시각적 경계 없이 매끄럽게 연결하는 플렉스 래퍼입니다.

https://
₩ 원 / 월 
<!-- 접두사 + 인풋 + 버튼 결합 -->
<div class="rw-input-group">
  <span class="rw-input-group-addon">https://</span>
  <input type="text" placeholder="my-service.com">
  <button class="rw-button rw-button--primary">연결</button>
</div>

<!-- 양방향 애드온 결합 (통화 표기) -->
<div class="rw-input-group">
  <span class="rw-input-group-addon">₩</span>
  <input type="text" value="25,000">
  <span class="rw-input-group-addon">원</span>
</div>

Valid & Invalid 유효성 검증 상태

웹 접근성 표준 aria-invalid="false"(성공) 및 aria-invalid="true"(오류) 속성을 통해 명확한 테두리 및 도움말 메시지를 표시합니다.

✓ 사용 가능한 도메인입니다.
✕ 올바른 이메일 형식을 입력하세요. 
<!-- 성공 상태 (Valid) -->
<label class="rw-meta">도메인</label>
<input type="text" value="readwell.design" aria-invalid="false">
<span class="rw-form-success">✓ 사용 가능한 도메인입니다.</span>

<!-- 오류 상태 (Invalid) -->
<label class="rw-meta">이메일</label>
<input type="email" value="wrong-email" aria-invalid="true">
<span class="rw-form-error">✕ 올바른 이메일 형식이 아닙니다.</span>
