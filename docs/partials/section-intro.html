1. Getting Started (시작하기)

개요 및 디자인 철학

Readwell CSS는 장시간 화면을 보아도 눈이 피로하지 않은 차분한 가독성과 실제 상용 제품 UI(Workspace, Dashboard, Backoffice)에 필요한 구조적 명확성을 함께 제공합니다.

  • 절제된 페이퍼 미학: 화려한 그림자, 과한 테두리 반경, 불필요한 모션을 억제하고 단정한 선과 여백으로 위계를 표현합니다.
  • 저채도 Semantic Matrix: 6종 상태 색상(primary, secondary, success, warning, danger, info)을 저채도로 조화롭게 적용합니다.
  • Zero Runtime Dependencies: 별도의 자바스크립트 없이 HTML5 표준 요소만으로 컴포넌트가 완성됩니다.

빠른 시작 (Installation)

단일 CDN 링크 또는 로컬 빌드 파일을 HTML 문서 상단에 삽입하면 즉시 적용됩니다.

<!-- CDN 링크로 빠르게 불러오기 -->
<link rel="stylesheet" href="https://callorange.github.io/readwell-css/dist/readwell.min.css">

<!-- 기본 HTML 마크업 예시 -->
<main class="rw-container" data-rw-theme="warm" data-rw-layout="reading">
  <article class="rw-reading">
    <h1>읽는 시간이 길수록 조용한 화면이 좋아진다.</h1>
    <p>본문 내용을 편안하게 작성하세요...</p>
  </article>
</main>

🎛️ 4대 HTML 제어 속성 (data-rw-*)

HTML <body> 또는 <html> 태그에 속성을 부여하여 전역 모드를 선언적으로 제어합니다. 스마트 프리셋 체계로 data-rw-layout만 지정해도 최적의 밀도가 자동 연동됩니다.

제어 속성 옵션 값 기본값 설명 및 권장 용도
data-rw-theme light, warm, dark light 테마 색온도: 내추럴 백상지(Light) vs 단행본 미색 크림지(Warm) vs 먹빛 흑연 야간지(Dark)
data-rw-layout
(구 surface 호환)		 reading, docs, workspace, fluid reading 레이아웃 아키타입 & 스마트 프리셋: 화면 목적별 최적 폭 및 기본 밀도 자동 연동 (reading[48rem]➔cozy, docs[80rem]➔comfortable, workspace[90rem]➔comfortable, fluid[100%]➔compact)
data-rw-density cozy, comfortable, compact 스마트 프리셋 연동 밀도 미세 조절 (오버라이드): 스마트 프리셋 기본값을 덮어쓰고 개별 패딩·여백을 수동 미세 조정할 때 사용
data-rw-eink true, false false 전자종이 정적 모드: 모든 전환 효과 및 애니메이션 차단

퓨어 페이퍼 테마 트리오 (Pure Paper Trio)

E-Ink 및 인쇄 종이 매체의 자연스러운 질감을 살린 3종의 표준 종이 테마입니다.

Light 📄 (내추럴 백상지) 기본 테마

맑고 정갈한 순수 종이 질감으로 깔끔하고 현대적인 가독성을 제공합니다.

조용한 화면이 만드는 집중

긴 글 읽기와 업무용 워크스페이스에 최적화된 시각 대비를 선사합니다.

Warm Paper 📖 (단행본 크림지) 눈 피로 완화

단행본 출판 도서의 미색 크림지 질감으로 장시간 독서 시 블루라이트 자극을 줄입니다.

단행본 질감의 편안함

실제 출판 책의 미색 용지 색온도를 재현하여 편안한 시야를 유지합니다.

Dark 🌙 (먹빛 흑연 야간지) 야간 저자극

칠흑 블랙 대신 눈부심 없는 흑연 먹빛으로 장시간 야간 독서 및 코딩에 적합합니다.

먹지 질감의 차분함

어두운 방에서도 대비 자극 없이 정보를 또렷하게 판독할 수 있습니다.
