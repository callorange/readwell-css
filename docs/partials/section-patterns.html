Code Block Header (.rw-code-block, .rw-code-header)

코드 블록 상단에 파일명과 언어 뱃지를 단정하게 표시하는 개발자 친화적인 문서 패턴입니다.

📄 server.ts TypeScript 
import http from 'node:http';

const server = http.createServer((req, res) => {
  res.writeHead(200, { 'Content-Type': 'text/plain' });
  res.end('Hello from Readwell CSS!');
});

server.listen(3000);
