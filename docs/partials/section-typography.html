Text Weights & Styles (텍스트 굵기 및 강조 서식)

진하게, 연하게, 이탤릭, 굵기 단계별 시맨틱 태그 및 유틸리티 클래스입니다.

진하게 (strong 태그 / .rw-bold): 핵심 키워드나 중요한 문장을 굵게(700) 표현합니다.

세미볼드 (.rw-semibold): 적절한 무게감(600)으로 UI 레이블을 강조합니다.

일반 굵기 (.rw-normal): 표준 본문 굵기(400)입니다.

가벼운 굵기 (.rw-light): 은은하고 얇은 굵기(300)입니다.

기울임꼴 (em / i 태그 / .rw-italic): 인용이나 강조 문장에 기울임 스타일을 적용합니다.

연하게 (small 태그 / .rw-muted): 부가 설명이나 보조 텍스트를 차분한 저채도 회색으로 표현합니다. 

<strong>진하게 (700)</strong> 또는 <span class="rw-bold">...</span>
<span class="rw-semibold">세미볼드 (600)</span>
<span class="rw-normal">일반 굵기 (400)</span>
<span class="rw-light">가벼운 굵기 (300)</span>
<em>기울임꼴</em>
<small class="rw-muted">연하게 보조 텍스트</small>

Inline Text (인라인 서식: kbd, mark, del, ins, samp 등)

표준 HTML5 인라인 텍스트 요소를 품격 있는 페이퍼 질감으로 스타일링합니다.

단축키를 누르려면 Ctrl + Shift + R 키를 입력하세요.

중요한 핵심 문장은 형광펜 하이라이트(mark)로 강조됩니다.

수정 전 내용은 취소선(del) 처리되고, 새로 추가된 내용은 추가선(ins)으로 표현됩니다.

터미널 출력 표본은 npm run build --success 형태로 나타납니다.

수학/화학식의 첨자: H2O (아래첨자) 및 E = mc2 (위첨자)

용어 설명 툴팁: CSS 및 HTML5 

<kbd>Ctrl</kbd> + <kbd>C</kbd>
<mark>형광펜 하이라이트</mark>
<del>취소선</del> / <ins>추가선</ins>
<samp>출력 결과</samp>
H<sub>2</sub>O / E = mc<sup>2</sup>
<abbr title="설명">약어</abbr>

Tufte-Style Sidenotes & Footnotes (사이드노트 및 본문 각주)

에드워드 터프티(Edward Tufte) 스타일의 장문 독서 최적화 각주 시스템입니다. 데스크톱(1080px 이상)에서는 본문 우측 마진에 나란히 배치되고, 모바일에서는 접이식 인라인 카드로 자동 반응형 전환됩니다.

긴 기술 문서나 아티클을 읽을 때 본문의 시선 흐름을 깨뜨리지 않고 참고 자료를 전달하는 것은 대단히 중요합니다. 사이드노트는 데스크톱에서 본문과 동일한 행 높이의 우측 여백에 배치되어 시선 분산을 방지합니다. 번호가 필요 없는 보조 메모의 경우 기호형 마진노트를 사용할 수도 있습니다. 마진노트는 번호 없이 자연스러운 주석 메모를 남길 때 유용합니다.

  1. 마크다운 및 출판 표준 규격의 하단 각주 예시입니다. ↩
<!-- 1. 표준 사이드노트 (번호 자동 매김) -->
본문 텍스트입니다.<label for="sn-1" class="rw-sidenote-number"></label>
<input type="checkbox" id="sn-1" class="rw-sidenote-toggle rw-sr-only">
<span class="rw-sidenote">데스크톱에서는 우측 마진에 부유하고 모바일에서는 접이식으로 변환됩니다.</span>

<!-- 2. 기호형 마진노트 (번호 없음) -->
참고 문장입니다.<label for="mn-1" class="rw-marginnote-symbol">⊕</label>
<input type="checkbox" id="mn-1" class="rw-marginnote-toggle rw-sr-only">
<span class="rw-marginnote">단순 보조 메모용 마진노트입니다.</span>

<!-- 3. 학술/출판 하단 각주 목록 -->
<section class="rw-footnotes" aria-label="Footnotes">
  <ol>
    <li id="fn-1">각주 설명 문구 <a href="#fnref-1" class="rw-footnote-backref">↩</a></li>
  </ol>
</section>

Accessibility Hidden (.rw-sr-only / .rw-visually-hidden)

화면에는 보이지 않지만 스크린 리더(Screen Reader)와 보조공학기기에는 온전히 낭독되는 W3C 표준 접근성 클리핑 클래스입니다. 키보드 Tab 탐색 시 화면에 나타나는 .rw-sr-only--focusable(본문 건너뛰기 링크 등)도 지원합니다.

아래 버튼에는 아이콘만 보이지만, 스크린 리더 사용자를 위한 대체 텍스트가 .rw-sr-only로 포함되어 있습니다:

← 브라우저 개발자 도구(F12) Elements 탭에서 <span class="rw-sr-only"> 구조를 확인해 보세요. 
<!-- 스크린 리더 전용 텍스트 -->
<button class="rw-button">
  <span aria-hidden="true">🔍</span>
  <span class="rw-sr-only">도서 및 문서 검색</span>
</button>
