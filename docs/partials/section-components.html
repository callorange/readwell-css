3종 크기(.rw-button--sm, 기본 Medium, .rw-button--lg), 전체 폭 블록(.rw-button--block), 외곽선(.rw-button--outline) 및 .rw-button-group을 지원합니다.

스타일 변형 (Variants)

로딩 및 비지 상태 ([aria-busy="true"])
버튼 그룹 (.rw-button-group)

Pure CSS Tooltip ([data-tooltip])

자바스크립트 없이 data-tooltip="안내 문구" 속성만으로 마우스 호버 및 키보드 포커스 시 상단에 말풍선 툴팁이 슬라이드 노출됩니다.

v0.2.0 전자종이 미학 
<!-- 버튼 툴팁 -->
<button class="rw-button" data-tooltip="새로운 문서를 작성합니다">문서 작성</button>
<button class="rw-button rw-button--primary" data-tooltip="즉시 발행됩니다">발행하기</button>

<!-- 텍스트 / 배지 툴팁 -->
<span class="rw-badge" data-tooltip="도움말 메시지">안내 배지</span>
<span data-tooltip="단어의 상세한 뜻을 표시합니다">용어 설명</span>

Process Stepper (.rw-steps, .rw-step)

온보딩, 결제, 신청서 및 단계별 워크플로우를 직관적으로 안내하는 순수 CSS 가로 단계 표시기입니다. 완료(.is-complete) 및 현재 진행 중(.is-active, [aria-current="step"]) 상태를 지원합니다.

  1. ✓ 계정 생성
  2. 2 프로필 작성
  3. 3 플랜 선택
  4. 4 완료

  </li>
  <li class="rw-step">

</ol>

Card (.rw-card) vs Panel (.rw-panel)

.rw-card는 독립된 콘텐츠 단위(기사, 상품)를, .rw-panel은 화면의 구조적 구획(사이드바, 설정 박스)을 담당합니다.

.rw-card (콘텐츠 카드)

독립된 읽기 단위를 표현합니다.

.rw-panel (구조 패널)

배경 및 구조적 영역을 분할합니다.

<article class="rw-card">카드 콘텐츠</article>
<div class="rw-panel">패널 구획</div>

Accordion / Disclosure (details.rw-accordion)

HTML5 표준 <details> 태그에 브라우저 기본 화살표를 제거하고, Paper & Ink 감성의 미니멀 쉐브론 화살표가 열림([open]) 시 180° 매끄럽게 회전하는 순수 CSS 인터랙션을 적용했습니다.

자주 묻는 질문 1: Readwell CSS는 자바스크립트가 필요한가요?
아닙니다. 100% 순수 CSS와 HTML5 표준 태그만으로 모든 컴포넌트와 애니메이션이 동작합니다.
자주 묻는 질문 2: E-Ink 테마와 다크 모드는 어떻게 적용하나요?
HTML 태그에 data-rw-theme="warm" 및 data-rw-mode="night" 속성을 지정하면 즉시 전환됩니다. 
<details class="rw-accordion">
  <summary>아코디언 제목 (클릭 시 쉐브론 회전)</summary>
  <p>펼쳐지는 상세 본문 내용...</p>
</details>

Modal Dialog (<dialog>)

HTML5 네이티브 <dialog> 태그 및 내부 <article> 구조(헤더, 본문, 푸터 버튼 그룹)를 완벽히 지원하는 모달 스타일입니다.

새 문서 작성

헤더와 푸터가 깔끔하게 구분되며, 백드롭과 ESC 키 닫기 접근성이 네이티브로 보장됩니다. 

<dialog id="my-dialog" class="rw-dialog">
  <article>
    <header>
      <h4>모달 제목</h4>
      <button onclick="this.closest('dialog').close()">✕</button>
    </header>
    <form method="dialog" class="rw-stack">
      <p>모달 상세 본문...</p>
      <footer>
        <button type="button" onclick="this.closest('dialog').close()">취소</button>
        <button type="submit" class="rw-button rw-button--primary">확인</button>
      </footer>
    </form>
  </article>
</dialog>

Dropdown & Dropup (네이티브 드롭다운, 상/하 위치, 스플릿 버튼)

details.rw-dropdown 구조로 자바스크립트 없이 메뉴가 열리며, 아래/위 방향(.rw-dropdown--up)과 좌/우 정렬(.rw-dropdown--right), 그리고 버튼 그룹과 결합한 스플릿 버튼 드롭다운을 완벽히 지원합니다.

1. 위치 방향 및 정렬 (아래 / 위 / 좌측 / 우측)
아래 좌측 (기본) ▾
  • 프로필 설정
  • 팀 워크스페이스
  • 로그아웃
아래 우측 정렬 ▾
  • 문서 내보내기
  • Markdown 복사
  • 문서 삭제
위로 열기 (.rw-dropdown--up) ▴
  • 최근 열람 문서
  • 북마크 바로가기
  • 휴지통
위로 우측 정렬 ▴
  • 환경 설정
  • 단축키 안내
2. 일체형 스플릿 버튼 드롭다운 (버튼 전체 아래로 자연스럽게 전개)
▾
  • 초안(Draft)으로 보관
  • 비공개로 저장
  • 삭제 및 휴지통 이동
▴
  • Markdown (.md)
  • HTML 웹 페이지
  • 텍스트 (.txt)
<!-- 1. 아래로 열림 (기본 좌측 / 우측 정렬) -->
<details class="rw-dropdown">
  <summary class="rw-button">아래 좌측 ▾</summary>
  <ul class="rw-dropdown-menu">...</ul>
</details>

<details class="rw-dropdown rw-dropdown--right">
  <summary class="rw-button">아래 우측 ▾</summary>
  <ul class="rw-dropdown-menu">...</ul>
</details>

<!-- 2. 위로 열림 (Dropup: .rw-dropdown--up) -->
<details class="rw-dropdown rw-dropdown--up">
  <summary class="rw-button">위로 열기 ▴</summary>
  <ul class="rw-dropdown-menu">...</ul>
</details>

<!-- 3. 일체형 스플릿 버튼 드롭다운 (버튼 전체 아래로 펼쳐짐) -->
<div class="rw-button-group">
  <button type="button" class="rw-button rw-button--primary">저장 및 발행</button>
  <details class="rw-dropdown">
    <summary class="rw-button rw-button--primary" aria-label="추가 옵션">▾</summary>
    <ul class="rw-dropdown-menu">
      <li><a href="#" class="rw-dropdown-item">초안으로 보관</a></li>
      <li><a href="#" class="rw-dropdown-item">비공개로 저장</a></li>
    </ul>
  </details>
</div>

Pagination (.rw-pagination)

현재 페이지 활성화(aria-current="page") 및 비활성화([aria-disabled="true"]) 상태를 지원하는 접근성 친화적 페이지네이션입니다.

기본 페이지네이션 (첫 페이지 - 이전 버튼 비활성화)
‹ 이전 1 2 3 다음 ›
중간 페이지 활성화 상태
‹ 이전 1 2 3 4 다음 › 
<nav class="rw-pagination" aria-label="Pagination">
  <span class="rw-pagination-prev" aria-disabled="true">‹ 이전</span>
  <span aria-current="page">1</span>
  <a href="#">2</a>
  <a href="#">3</a>
  <a href="#" class="rw-pagination-next">다음 ›</a>
</nav>
