# Sumi (수묵 水墨) 테마 종합 개선 계획서 및 구현 체크리스트

> **"전통 서예의 필세(筆勢)와 흑백농담을 계승하고, 프로덕션 수준의 모던 웹 표준과 듀얼 렌더링 엔진을 구축한다."**  
> 본 문서는 `examples/sumi` 수묵 테마의 조형적 완성도를 보존하면서, 안정적인 점진적 향상(Progressive Enhancement)과 실시간 검증을 달성하기 위한 **4단계 실행 계획 및 체크리스트**입니다.

---

## 🏛️ 핵심 개발 원칙 (Core Principles)

1. **무손실 호환성 (Lossless Compatibility)**:
   - 기존의 모든 원본 에셋(PNG/JPG)은 1바이트의 유실 없이 그대로 보존합니다.
   - WebP 변환은 최신 브라우저를 위한 점진적 향상으로 적용하며, 미지원 브라우저를 위한 구형 포맷 폴백을 100% 보장합니다.
2. **듀얼 렌더링 & 실시간 검증 (Dual Engine & Live Evaluation)**:
   - SVG 벡터 방식이 서예 특유의 유기적인 '손맛'을 충분히 살릴 수 있는지 검증하기 위해, **기존 비트맵 방식과 신규 SVG 방식을 병렬로 탑재**합니다.
   - 독자 및 개발자가 화면에서 클릭 한 번으로 두 방식을 즉시 전환·비교할 수 있는 실시간 A/B 스위처를 제공합니다.
3. **Readwell 코어 철학 연동 (Readwell Philosophy)**:
   - E-Ink 디스플레이 친화성, 긴 글 가독성(Long-form Reading), 제로 디펜던시(Zero Dependency)의 가치를 수묵 미학과 융합합니다.
4. **단계별 격리 검증 (Step-by-Step Validation)**:
   - 한 번에 대규모 수정을 가하지 않고, 각 Phase가 완료될 때마다 브라우저에서 실제 작동 상태를 검증한 뒤 다음 단계로 전진합니다.

---

## ⚖️ 듀얼 렌더링 (비트맵 vs SVG) 평가 기준표 (Evaluation Matrix)

독자 및 개발자가 두 방식을 직접 테스트할 때 객관적으로 판단할 수 있는 4대 평가 기준입니다:

| 평가 지표 | 비트맵 방식 (WebP + PNG/JPG) | SVG 벡터 방식 | 승자 판정 기준 |
| :--- | :--- | :--- | :--- |
| **전송량 (Transfer Size)** | WebP 압축 시 약 150~250KB | 인라인 코드 약 5~15KB | **SVG 압승** (90% 이상 절감) |
| **시각적 손맛 (Artistic Fidelity)** | 서예가의 실제 붓질, 비백, 화선지 번짐 손맛 100% 보존 | 수학적 곡선으로 인해 미세하게 인위적일 가능성 있음 | **1:1 육안 비교로 판정** |
| **디스플레이 확장성 (High DPI)** | 200%, 300% 모바일 레티나 화면에서 미세 흐림 가능 | 어떤 해상도(4K/8K)나 확대 비율에서도 칼같은 선명도 유지 | **SVG 압승** |
| **렌더링 부하 (Scroll FPS)** | 브라우저 디코딩 후 비트맵 단순 페인팅 (GPU 부하 극소) | 복잡한 SVG 필터나 실시간 노이즈 연산 시 모바일 GPU 부하 가능 | **저사양 기기 60fps 유지 여부로 판정** |
| **테마 확장성 (Color Tuning)** | 색상별(농묵, 주사, 담묵, 금묵) 별도 에셋 또는 마스크 필요 | CSS `fill`, `stroke` 변수 하나로 임의의 안료 색상 즉시 대응 | **SVG 압승** |

## 🛡️ 조형 무결성 거버넌스 (Design Integrity Rules)

구현 중 절대 훼손되지 않아야 할 서예 미학의 4대 기본 수칙입니다:

1. **Anti-Bulking (슬림한 선율 보존)**: 프로그레스 바와 슬라이더의 높이는 `12px`(획 두께 6~8px)를 절대 기준으로 유지합니다.
2. **기필(起筆)과 수필(收筆)의 호응**: 시작점의 유선형 둥근 붓머리와 끝단의 날렵한 테이퍼링(소멸 궤적)을 보존합니다.
3. **트랙과 채움의 1:1 실루엣 합치**: 담묵 트랙과 농묵 채움은 동일한 수묵 궤적 마스크를 공유해야 합니다.
4. **여백지미 (余白之美)**: 인위적인 기하학적 박스나 네온 테두리를 배제하고, 화선지의 호흡과 먹의 농담으로 문맥을 표현합니다.
