읽는 시간이 길수록 조용한 화면이 좋아진다

Readwell CSS는 E-Ink 디스플레이에서 얻은 절제된 디자인 원칙을 일반 웹 UI에 적용하는 CSS 프레임워크입니다. 전자책 리더를 흉내 내는 것이 아니라, 텍스트 중심 화면은 더 오래 편하게 읽게 만들고, 제품형 화면은 더 차분하지만 더 명확하게 보이게 만드는 것을 목표로 합니다.

핵심 설계 방향

불필요한 장식용 색상은 억제하고, 구조는 주로 여백·선·글자 위계로 표현합니다. 주요 액션과 성공/경고/오류/진행 상태에는 저채도 semantic color를 적극적으로 사용합니다.

1. 타이포그래피와 가독성

현대 웹 UI는 정보를 빠르게 스캔하는 데 치중되어 있어 긴 글을 읽을 때 눈의 피로를 유발할 수 있습니다. Readwell은 본문 너비를 44rem 내외로 제한하고 행간을 1.7 이상으로 설정하여 호흡이 긴 글에서도 편안함을 유지합니다.

“조용함은 무구조를 뜻하지 않는다. 장문 화면에서는 읽기 편해야 하고, 제품 화면에서는 구조와 상태가 빠르게 판독되어야 한다.”

2. 코드 블록 및 테이블 예시

코드 블록 역시 차분한 종이 질감의 배경과 얇은 경계선으로 표현됩니다.

/* Readwell CSS Token Structure */
:root {
  --rw-paper: #faf8f3;
  --rw-text: #1f1f1f;
  --rw-primary: #496a8b;
}
