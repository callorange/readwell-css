Readwell CSS 종합 컴포넌트 명세

Readwell CSS가 제공하는 모든 HTML5 시맨틱 기본 요소, 클래스 기반 컴포넌트, 시맨틱 컬러 매트릭스 및 인터랙티브 동작을 한 화면에서 탐색하고 검증할 수 있는 키친싱크입니다.

💡 우측 하단의 ⚙️ Mode Switcher를 열어 테마(Light/Warm), 표면(Surface), 여백 밀도(Density), E-Ink 정적 모드를 전환해보세요. 모든 컴포넌트와 폼, 탭, 코드 블록이 실시간으로 자연스럽게 적응합니다.

7. Native Interactive Elements

Readwell CSS의 설계 철학은 무엇인가요?

E-Ink 디스플레이에서 얻은 절제된 디자인 원칙을 적용하여 화려한 그림자와 애니메이션을 억제하고, 오직 선·여백·저채도 시맨틱 컬러로 편안한 가독성을 제공합니다.

JavaScript 의존성이 필요한가요?

아닙니다. Readwell CSS는 100% Zero Runtime JavaScript로 동작하며 모든 인터랙션은 HTML5 표준 태그(dialog, details 등)를 우선 활용합니다.

네이티브 모달 다이얼로그

HTML5 <dialog> 태그와 ::backdrop을 적용한 순수 네이티브 모달입니다. E-Ink 및 일반 브라우저에서 가볍고 안전하게 렌더링됩니다.
