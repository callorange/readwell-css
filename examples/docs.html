Readwell CSS 공식 가이드

E-Ink 디스플레이에서 영감을 얻은 긴 글 가독성과 제품 UI를 위한 저자극 순수 CSS 프레임워크입니다. 모든 컴포넌트는 Zero Runtime JavaScript 및 표준 시맨틱 HTML5 태그를 기반으로 작동합니다.

1. Getting Started (시작하기)

개요 및 디자인 철학

Readwell CSS는 장시간 화면을 보아도 눈이 피로하지 않은 차분한 가독성과 실제 상용 제품 UI(Workspace, Dashboard, Backoffice)에 필요한 구조적 명확성을 함께 제공합니다.

  • 절제된 페이퍼 미학: 화려한 그림자, 과한 테두리 반경, 불필요한 모션을 억제하고 단정한 선과 여백으로 위계를 표현합니다.
  • 저채도 Semantic Matrix: 6종 상태 색상(primary, secondary, success, warning, danger, info)을 저채도로 조화롭게 적용합니다.
  • Zero Runtime Dependencies: 별도의 자바스크립트 없이 HTML5 표준 요소만으로 컴포넌트가 완성됩니다.

빠른 시작 (Installation)

단일 CDN 링크 또는 로컬 빌드 파일을 HTML 문서 상단에 삽입하면 즉시 적용됩니다.

<!-- CDN 링크로 빠르게 불러오기 -->
<link rel="stylesheet" href="https://callorange.github.io/readwell-css/dist/readwell.min.css">

<!-- 기본 HTML 마크업 예시 -->
<main class="rw-container" data-rw-theme="warm" data-rw-surface="reading" data-rw-density="cozy">
  <article class="rw-reading">
    <h1>읽는 시간이 길수록 조용한 화면이 좋아진다.</h1>
    <p>본문 내용을 편안하게 작성하세요...</p>
  </article>
</main>

🎛️ 4대 HTML 제어 속성 (data-rw-*)

HTML <body> 또는 <html> 태그에 속성을 부여하여 전역 모드를 선언적으로 제어합니다.

제어 속성 옵션 값 기본값 설명 및 권장 용도
data-rw-theme light, warm light 테마 색온도: 내추럴 백상지(Light) vs 단행본 미색 크림지(Warm)
data-rw-surface reading, workspace, dashboard, dense reading 화면 표면: 장문 독서 / 문서 협업 / 운영 콘솔 / 고밀도 데이터 표
data-rw-density cozy, comfortable, compact comfortable 여백 밀도: 여유로운 여백 / 표준 균형 / 압축 데이터 뷰
data-rw-eink true, false false 전자종이 정적 모드: 모든 전환 효과 및 애니메이션 차단

퓨어 페이퍼 테마 듀오 (Pure Paper Duo)

E-Ink 및 인쇄 종이 매체의 자연스러운 질감을 살린 2종의 표준 테마입니다.

Light 📄 (내추럴 백상지) 기본 테마

맑고 정갈한 순수 종이 질감으로 깔끔하고 현대적인 가독성을 제공합니다.

조용한 화면이 만드는 집중

긴 글 읽기와 업무용 워크스페이스에 최적화된 시각 대비를 선사합니다.

Warm Paper 📖 (단행본 크림지) 눈 피로 완화

단행본 출판 도서의 미색 크림지 질감으로 장시간 독서 시 블루라이트 자극을 줄입니다.

단행본 질감의 편안함

실제 출판 책의 미색 용지 색온도를 재현하여 야간 독서에 적합합니다.

2. Layout (레이아웃)

Container & Reading

.rw-container는 페이지 최대 폭(72rem)을 안정적으로 제한하며, .rw-reading은 긴 글 가독성을 위해 본문 폭을 44rem으로 최적화합니다.

.rw-container (기본 컨테이너 영역)
.rw-reading (최대 44rem 독서 최적화 영역)

Text Weights & Styles (텍스트 굵기 및 강조 서식)

진하게, 연하게, 이탤릭, 굵기 단계별 시맨틱 태그 및 유틸리티 클래스입니다.

진하게 (strong 태그 / .rw-bold): 핵심 키워드나 중요한 문장을 굵게(700) 표현합니다.

세미볼드 (.rw-semibold): 적절한 무게감(600)으로 UI 레이블을 강조합니다.

일반 굵기 (.rw-normal): 표준 본문 굵기(400)입니다.

가벼운 굵기 (.rw-light): 은은하고 얇은 굵기(300)입니다.

기울임꼴 (em / i 태그 / .rw-italic): 인용이나 강조 문장에 기울임 스타일을 적용합니다.

연하게 (small 태그 / .rw-muted): 부가 설명이나 보조 텍스트를 차분한 저채도 회색으로 표현합니다. 

<strong>진하게 (700)</strong> 또는 <span class="rw-bold">...</span>
<span class="rw-semibold">세미볼드 (600)</span>
<span class="rw-normal">일반 굵기 (400)</span>
<span class="rw-light">가벼운 굵기 (300)</span>
<em>기울임꼴</em>
<small class="rw-muted">연하게 보조 텍스트</small>

Inline Text (인라인 서식: kbd, mark, del, ins, samp 등)

표준 HTML5 인라인 텍스트 요소를 품격 있는 페이퍼 질감으로 스타일링합니다.

단축키를 누르려면 Ctrl + Shift + R 키를 입력하세요.

중요한 핵심 문장은 형광펜 하이라이트(mark)로 강조됩니다.

수정 전 내용은 취소선(del) 처리되고, 새로 추가된 내용은 추가선(ins)으로 표현됩니다.

터미널 출력 표본은 npm run build --success 형태로 나타납니다.

수학/화학식의 첨자: H2O (아래첨자) 및 E = mc2 (위첨자)

용어 설명 툴팁: CSS 및 HTML5 

<kbd>Ctrl</kbd> + <kbd>C</kbd>
<mark>형광펜 하이라이트</mark>
<del>취소선</del> / <ins>추가선</ins>
<samp>출력 결과</samp>
H<sub>2</sub>O / E = mc<sup>2</sup>
<abbr title="설명">약어</abbr>

Blockquote & Code Block

인용문과 코드 블록은 과한 배경색 없이 단정한 보더와 여백으로 내용을 부각합니다.

"읽는 시간이 길수록 조용한 화면이 좋아진다." — Readwell Team
const readwell = { mode: 'pure-paper', runtime: 'zero-js' };
<blockquote>"인용문 내용"</blockquote>
<pre><code>const code = "Hello Readwell";</code></pre>

Accessibility Hidden (.rw-sr-only / .rw-visually-hidden)

화면에는 보이지 않지만 스크린 리더(Screen Reader)와 보조공학기기에는 온전히 낭독되는 W3C 표준 접근성 클리핑 클래스입니다. 키보드 Tab 탐색 시 화면에 나타나는 .rw-sr-only--focusable(본문 건너뛰기 링크 등)도 지원합니다.

아래 버튼에는 아이콘만 보이지만, 스크린 리더 사용자를 위한 대체 텍스트가 .rw-sr-only로 포함되어 있습니다:

← 브라우저 개발자 도구(F12) Elements 탭에서 <span class="rw-sr-only"> 구조를 확인해 보세요. 
<!-- 스크린 리더 전용 텍스트 -->
<button class="rw-button">
  <span aria-hidden="true">🔍</span>
  <span class="rw-sr-only">도서 및 문서 검색</span>
</button>

<!-- 본문 바로가기 건너뛰기 링크 (Tab 포커스 시 표시) -->
<a href="#main-content" class="rw-sr-only rw-sr-only--focusable">본문 바로가기</a>

4. Forms & Validation (폼 컨트롤 및 유효성 검증)

Input, Select & Textarea

밀도 시스템과 연동되는 기본 폼 컨트롤입니다.

<label class="rw-meta">이름</label>
<input type="text" placeholder="홍길동">

<label class="rw-meta">소개</label>
<textarea rows="3" placeholder="내용 입력..."></textarea>

Custom Checkbox & Radio

Paper & Ink 철학에 부합하는 순수 CSS 사각/원형 커스텀 컨트롤입니다. 완벽한 네이티브 포커스 링과 라벨 클릭 토글을 지원합니다. 

<label>
  <input type="checkbox" checked> 동의함
</label>

<label>
  <input type="radio" name="group" checked> 옵션 A
</label>
<label>
  <input type="radio" name="group"> 옵션 B
</label>

Toggle Switch (슬라이더 스위치)

표준 체크박스에 role="switch" 속성만 부여하면 슬라이더 토글 스위치로 자동 전환됩니다. 

<label>
  <input type="checkbox" role="switch" checked> 자동 저장 활성화

Slider Range Control (<input type="range">)

E-Ink 독서 화면의 글자 크기, 줄 간격, 화면 밀도 등을 부드럽게 조절할 수 있는 미니멀 Paper & Ink 슬라이더입니다. 호버 시 썸(Thumb) 확대 피드백과 네이티브 포커스 링을 지원합니다.

기본값: 16px 
<!-- 표준 슬라이더 컨트롤 -->
<label class="rw-meta">글자 크기</label>
<input type="range" min="12" max="24" value="16">

<!-- 비활성화 상태 -->
<input type="range" disabled>

Input Group (결합 입력창 .rw-input-group)

텍스트 입력 필드 좌우에 고정 단위(₩, $, %), 프로토콜(https://), 검색 버튼 등을 시각적 경계 없이 매끄럽게 연결하는 플렉스 래퍼입니다.

https://
₩ 원 / 월

</div>

<!-- 양방향 애드온 결합 (통화 표기) -->

Valid & Invalid 유효성 검증 상태

웹 접근성 표준 aria-invalid="false"(성공) 및 aria-invalid="true"(오류) 속성을 통해 명확한 테두리 및 도움말 메시지를 표시합니다.

✓ 사용 가능한 도메인입니다.
✕ 올바른 이메일 형식을 입력하세요. 
<!-- 성공 상태 (Valid) -->
<label class="rw-meta">도메인</label>

<span class="rw-form-success">✓ 사용 가능한 도메인입니다.</span>

<!-- 오류 상태 (Invalid) -->
<label class="rw-meta">이메일</label>
<input type="email" value="wrong-email" aria-invalid="true">
<span class="rw-form-error">✕ 올바른 이메일 형식이 아닙니다.</span>

Card (.rw-card) vs Panel (.rw-panel)

.rw-card는 독립된 콘텐츠 단위(기사, 상품)를, .rw-panel은 화면의 구조적 구획(사이드바, 설정 박스)을 담당합니다.

.rw-card (콘텐츠 카드)

독립된 읽기 단위를 표현합니다.

.rw-panel (구조 패널)

배경 및 구조적 영역을 분할합니다.

<article class="rw-card">카드 콘텐츠</article>
<div class="rw-panel">패널 구획</div>

Callouts / Alerts (4종 알림 메시지)

안내, 성공, 경고, 오류 알림 박스입니다.

Success: 작업이 정상적으로 완료되었습니다.
Warning: 저장되지 않은 변경사항이 있습니다.
Danger: 연결이 끊어졌습니다. 다시 시도하세요.

<div class="rw-callout rw-callout--danger">오류 메시지</div>

Accordion / Disclosure (details.rw-accordion)

HTML5 표준 <details> 태그에 브라우저 기본 화살표를 제거하고, Paper & Ink 감성의 미니멀 쉐브론 화살표가 열림([open]) 시 180° 매끄럽게 회전하는 순수 CSS 인터랙션을 적용했습니다.

자주 묻는 질문 1: Readwell CSS는 자바스크립트가 필요한가요?
아닙니다. 100% 순수 CSS와 HTML5 표준 태그만으로 모든 컴포넌트와 애니메이션이 동작합니다.
자주 묻는 질문 2: E-Ink 테마와 다크 모드는 어떻게 적용하나요?
HTML 태그에 data-rw-theme="warm" 및 data-rw-mode="night" 속성을 지정하면 즉시 전환됩니다. 
<details class="rw-accordion">
  <summary>아코디언 제목 (클릭 시 쉐브론 회전)</summary>
  <p>펼쳐지는 상세 본문 내용...</p>
</details>

Modal Dialog (<dialog>)

HTML5 네이티브 <dialog> 태그 및 내부 <article> 구조(헤더, 본문, 푸터 버튼 그룹)를 완벽히 지원하는 모달 스타일입니다.

새 문서 작성

헤더와 푸터가 깔끔하게 구분되며, 백드롭과 ESC 키 닫기 접근성이 네이티브로 보장됩니다. 

<dialog id="my-dialog" class="rw-dialog">
  <article>
    <header>
      <h4>모달 제목</h4>
      <button onclick="this.closest('dialog').close()">✕</button>
    </header>
    <form method="dialog" class="rw-stack">
      <p>모달 상세 본문...</p>
      <footer>
        <button type="button" onclick="this.closest('dialog').close()">취소</button>
        <button type="submit" class="rw-button rw-button--primary">확인</button>
      </footer>
    </form>
  </article>
</dialog>

7. Modes & Customization (모드 및 커스터마이징)

Surface Family (화면 표면)

data-rw-surface 속성으로 용도별 화면 특성을 지정합니다.

  • reading: 장문 독서 최적화 (본문 폭 48rem 제한 및 넉넉한 타이포 행간)
  • workspace: 문서형 협업 도구 및 사이드바 레이아웃 (컨테이너 80rem)
  • dashboard: 운영 콘솔 및 지표 그리드 (컨테이너 84rem)
  • dense: 고밀도 데이터 테이블 및 필터 (컴팩트 밀도 자동 활성화)

Density System (여백 밀도)

data-rw-density 속성으로 테이블 셀, 버튼, 인풋, 그리드 여백을 유기적으로 조절합니다.

  • cozy: 터치 인터페이스 및 여유로운 독서 여백
  • comfortable: 표준 균형 여백 (기본값)
  • compact: 대량 데이터 조회를 위한 압축 뷰

E-Ink Mode (전자종이 정적 렌더링 모드)

data-rw-eink="true" 속성 또는 @media (update: slow) 환경에서 모든 애니메이션과 전환 효과를 차단하여 눈 피로를 완벽히 제거합니다.
